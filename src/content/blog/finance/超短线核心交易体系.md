**要信早信，聚焦核心；**

**要信早信：适用于新题材（有炒作预期）启动、爆发时，快速上车参与，适用于题材老核心突然异动；要信早信需要一定的认知和理解力来辅助决策是否出手及出手的仓位，模棱两可的机会，放弃即可；涵盖了市场上热点模式和首板模式等；**

**聚焦核心：题材启动爆发后，核心股独树一帜，龙相尽显之时，它就是最核心的，也是你必须要参与的；核心，分为核心主升和核心低吸，主升期，主要是抢筹码（半路、追高和打板），主升期及渡劫日，主升期给到了低吸机会，或者核心股渡劫日给到的急杀低吸机会，主要是捡筹码（低吸介入）；涵盖了市场上合法前提下最稳定、最安全且最暴利的模式；这是老师的核心！**

模式：核心主升+核心低吸

核心主升买点：

1、核心股分歧日（炸板急杀、多空博弈）（最优买点）

2、渡劫日买入（有风险，利润高的时候大胆买）（渡劫成功化龙成妖；失败立刻卖）

3、预判分歧，竞价低时买入

主升做 T 策略：

1、加 T，滚动加 T（主升期多做加 T，不做减 T）

2、平 T，仓位不变降低成本，早盘低买，尾盘高卖

3、预测有风险，减 T，减少大回撤

主升卖出时机：（长持有，大格局）

1、当日盘中断板

2、或断板次日开盘

3、抖音/股吧爆吹（情绪过热）

4、板上墨迹，拉升不果断

核心低吸买点：（短持有，快进快出）

1、龙头首阴，龙头短板后的第一根阴线

日内深水急杀、缓跌尾盘不跌停、隔日开盘深水

2、主升期分歧日（前提题材逻辑没变）

3、关键节点龙头短板，看同题材首板个股，等首板分歧，判断题材是否纯正，买入，博补涨（套利 10-15%左右就要立场）

## 第一部分：如何找到核心股

## 一、什么是核心股？

#### 核心股的五大特征（必须记住）

```plain
1. 题材纯正度最高 ✅
2. 板块带动性最强 ✅
3. 资金认可度最高 ✅
4. 走势独立性强 ✅
5. 有明显辨识度 ✅
```

#### 感性认知

```plain
看到核心股，会有心动的感觉
就像在人群中看到了她
```

#### 核心股 vs 龙头 vs 妖股

```plain
普通个股
  ↓ 走出辨识度
核心股（渡劫前）
  ↓ 继续打高度 + 带动板块
龙头（对市场有带动作用）

如果：
✅ 打高度 + 带动市场 → 龙头
❌ 只打高度 + 无带动作用 → 独立妖股
```

#### 第二步：用节点+区间统计筛选

##### 什么是节点？

```plain
节点 = 核心股出生的日子

小节点 → 小周期
大节点 → 大周期
```

##### 容易出节点的 6 种情况

```plain
1. 指数见底日
2. 指数与题材共振爆发日
3. 上涨家数冰点日（800涨 vs 4000跌）
4. 连板冰点日（最高板≤3板）
5. 指数连续冰点日
6. 龙头断板日（前后1-2天）⭐ 最重要
```

##### 区间统计怎么用？

```plain
以节点日为起点
→ 统计题材内个股的区间涨幅排名
→ 排名第一的就是核心股

例子：
克来机电断板日(2.27) = 节点
当天首板的安奈儿 → 补涨龙
```


```tsx
const 参与策略 = {

  },

  '40-60%涨幅': {
    判断: '主升初期',
    仓位: '2-3成',

  },

  '80%+涨幅': {
    判断: '主升后期',
    仓位: '空仓观望',

  }

```

#### 正常高度预期

```plain
监管严格期：主板6-7板天花板
监管放松期：主板10-13板
大题材周期：主板可到13-15板（如华为周期）

创业板高度 ≈ 主板高度 × 0.7
```

## 四、快速识别核心股的技巧

#### 竞价观察法（9:15-9:25）

```plain
✅ 一字封单最大 → 可能是核心
✅ 竞价成交量显著放大 → 资金认可
✅ 竞价弱转强 → 有承接
```

#### 盘中验证法

```plain
✅ 分歧能快速回封 → 是核心
✅ 封板后不开板 → 资金坚决
✅ 尾盘拉升 → 次日有预期
```

#### 龙虎榜验证法

```plain
✅ 买方游资席位多 → 资金认可
✅ 连续上榜 → 持续性强
✅ 顶级游资进场 → 高度有保障
```

## 第二部分：核心主升战法

## 一、主升战法核心逻辑

#### 什么是主升？

```plain
主升 = 核心股连续拉升阶段
     = 最容易赚钱的阶段
     = 格局大于努力的阶段
```

#### 主升期的三大特征

```plain
1. 连续涨停或大涨（少回调）
2. 成交量持续放大
3. 板块跟随上涨
```

***

## 二、主升买入时机

#### 买点 1：分歧日买入（最安全）⭐⭐⭐⭐⭐

**什么是分歧日？**

```plain
连续涨停后首次开板分歧
→ 早盘炸板急杀
→ 多空激烈博弈
→ 这是最好的买点！
```

**买入信号**：

```plain
✅ 开板后急杀-5%~-8%
✅ 分时量能放大后萎缩
✅ 盘口有大单承接
✅ 板块小弟护盘

操作：分批买入，急杀越深越买
```

**实战案例**：

```plain
艾艾精工（3.18）
→ 一字板开后急杀到-8%
→ 原计划做龙首阴
→ 结果主力日内回封，躺赢4板
```

***

#### 买点 2：渡劫日买入（适合胆大者）⭐⭐⭐⭐

**什么是渡劫？**

```plain
核心股在关键位置面临考验
→ 突破前高
→ 连板关口（如5进6）
→ 题材分歧

渡劫成功 → 化龙成妖
渡劫失败 → 换其他票
```

**买入方式**：

```plain
方式1：隔夜一字板
方式2：日内分歧回封时排板

仓位：3-4成
```

**实战案例**：

```plain
克来机电（2.8 五进六渡劫日）
→ 跨节前最高标
→ 早盘爆量分歧
→ 第二次开板回封时排板
→ 3成仓14:30成交
→ 节后从6板拿到13板
```

***

#### 买点 3：竞价买入（适合计划交易）⭐⭐⭐

**适用场景**：

```plain
前一晚复盘已做好计划
→ 预判第二天分歧
→ 竞价符合预期
→ 竞价直接买入
```

**操作要点**：

```plain
9:20-9:25之间下单
竞价价格可接受就买
如竞价太强可开盘后等分歧
```

## 三、主升持有策略

#### 核心原则：捏死不动！

```plain
✅ 拿住核心，格局持有
✅ 不看小波动
✅ 不担心回调
✅ 相信核心逻辑
✅ 直至大阴线离场
```

#### 主升期做 T 技巧

**加 T 策略**（增加格局）：

```plain
场景：主升期，想加大仓位

操作：
早盘买入2-3成（当天买入不能卖）
冲高卖出底仓2成
→ 当天最坏情况只回撤新买的2-3成
→ 第二天底仓更重了
→ 变相增加格局
```

**平 T 策略**（维持仓位）：

```plain
早盘买入2成
尾盘卖出2成底仓
→ 仓位不变
→ 降低成本
```

**减 T 策略**（控制风险）：

```plain
场景：预期有风险

操作：
早盘买入1成
冲高卖出2-3成底仓
→ 底仓减少了
→ 主动降低风险
```

**⚠️ 核心提醒**：

```plain
主升期尽量做加T，不做减T！
做T是为了拿住股票，不是为了T飞！
```

## 四、主升卖出信号

#### 唯一标准：大阴线！

**大阴线定义**：

```plain
1. 跌幅≥-5%
2. 或者跌停
3. 或者断板且不能反包
```

**卖出时机**：

```plain
✅ 断板当日盘中
✅ 或断板次日开盘
✅ 越早越好
```

#### 提前预警信号（可提前减仓）

```plain
⚠️ 论坛/抖音各种爆吹（情绪过热）
⚠️ 涨幅已超历史同类标的
⚠️ 板上磨叽，拉升不果断
⚠️ 第三次下均线不能快速拉回
```

## 第三部分：核心低吸战法

## 一、核心低吸的定义

#### 什么是核心低吸？

```plain
核心低吸 = 核心股分歧日低点买入
         = 短期套利操作
         = 持有2-3天，赚10-15%
```

#### 为什么要做核心低吸？

```plain
✅ 安全性高（核心股不会A杀）
✅ 确定性强（流动性好）
✅ 收益稳定（10-15%）
✅ 规避中高位风险
```

***

## 二、核心低吸的三种买点

#### 买点 1：龙头首阴（最经典）⭐⭐⭐⭐⭐

**什么是龙头首阴？**

```plain
龙头断板后的第一根阴线
```

**三种介入形态**：

**形态 A：日内深水急杀**

```plain
断板当日急杀到-7%~-10%
→ 符合预期，打入第一笔
```

**形态 B：缓跌尾盘不死**

```plain
缓慢下跌，尾盘不封死跌停
→ 尾盘打入第一笔
```

**形态 C：隔日开盘深水**

```plain
断板当日封死跌停，买不到
→ 次日开盘杀得越深，仓位越重
```

**卖出策略**：

```plain
持有2天左右
累计涨幅达到10-15%撤离
不意淫二波
```

**实战案例**：

```plain
克来机电龙首阴（2.28-3.1）
→ 盈利约16%
→ 持有2天左右
```

***

#### 买点 2：主升期分歧日

**适用场景**：

```plain
核心股主升途中出现分歧
→ 早盘急杀
→ 但题材逻辑没变
→ 低吸做T
```

**操作方式**：

```plain
早盘急杀-5%以上时买入
当天冲高后卖出（或持有1-2天）
仓位：2-3成
```

**适用场景**：

```plain
龙头断板日当天
→ 新首板个股分歧
→ 可能是补涨龙
```

## 三、核心低吸的纪律

#### 必须遵守的 4 条纪律

```plain
1. 只做核心股的低吸
   ❌ 不做杂毛的低吸

2. 持有时间不超过3天
   ❌ 不贪心，不格局

3. 达到10-15%必须走
   ❌ 不意淫翻倍

4. 有主升题材时不做
   ✅ 交易要有优先级
```

## 四、核心低吸 vs 核心主升

#### 对比表

| **维度**   | **核心主升** | **核心低吸** |
| -------- | -------- | -------- |
| **目标**   | 吃主升浪     | 短期套利     |
| **持有周期** | 5-10 天    | 2-3 天     |
| **收益预期** | 50-100%+ | 10-20%   |
| **仓位**   | 3-5 成     | 2-3 成     |
| **风险**   | 中        | 低        |
| **操作难度** | 需要格局     | 相对简单     |
| **优先级**  | ⭐⭐⭐⭐⭐    | ⭐⭐⭐      |

#### 使用时机

```plain
有主升题材时：
✅ 全力做核心主升
❌ 不做核心低吸

无主升题材时：
✅ 做核心低吸
✅ 规避中高位风险
```

## 第四部分：完整实战案例

## 案例 1：克来机电完整周期

#### 基本信息

```plain
题材：跨节+机器人+Sora
时间：2024.2.7 - 2.29
高度：13连板
```

#### 完整操作

**买入（2.8 五进六）**：

```plain
背景：跨节龙选拔，换村长利好
渡劫：5进6是关键
时机：早盘爆量分歧，第二次回封
仓位：3成排板，14:30成交
预期：节后3-4板
```

**持有（2.9-2.27）**：

```plain
策略：捏死不动
操作：主升期做加T
调整：预期从3-4板调整到12-13板
```

**卖出（2.27-2.28）**：

```plain
信号1：论坛/抖音爆吹（情绪过热）
```
